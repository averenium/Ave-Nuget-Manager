Split-badge options

The button on a project row that gives one target framework its own version (#82). Everything below is drawn at the real 10px/12px it ships at, with a 2× copy beside it, because at this size the difference between two icons is the whole decision.

Icon candidates — same button, same colours

IconReal size2×What it says, and against it
Install (current) “Make a reference here” — already its meaning on the Install button and the transitive pin row. Reads as an install, not as a split, so it says the result and not the change of shape.
Split One reference becoming two — exactly the operation. Busiest of the set at 12px, and the two arrowheads nearly merge.
Pin “Pin this framework to this version” — the word the issue itself uses for a per-framework reference. Clear at size, and distinct from everything else in the panel.
Plus The most legible mark there is at 12px, and the least specific: “add something”. Nothing says the other frameworks stay behind.
Arrow to a wall “Send this version into that framework.” Directional, so the badge reads left to right as a sentence. Close to the row's own ↑ button, which may blur the two.
Brackets “Scoped to this”, the way a condition scopes a group. Quiet and legible, but abstract enough that it needs to be learned once.
No icon A filled accent pill already reads as pressable. Shortest, and the only one that never has to be explained — at the cost of saying nothing about what pressing does.

Badge shapes — with the pin, for comparison

ShapeRestHoverNote
Filled pill (current) Loudest, and unmistakably a button. Three or five of them under a row is a lot of accent colour for something that is not the row's main action.
Outlined pill Quieter at rest, fills in on hover. This is what was there before the icon, and it read as a label — the icon may be what fixes that rather than the fill.
Neutral chip Matches the TFM badges elsewhere in the panel at rest, becomes the accent button on hover. Consistent, but at rest it is the same thing that already means “a fact”, not “an action”.
Two-tone net8.0 net8.0 The icon gets its own darker segment, the way a split button looks. Strongest “press me” of the set, and the widest — five of these will wrap.
Square, not pill The 3px radius every other button in the panel uses. Blends in — which is the argument for it and against it: the pill is what marks these as a different kind of action.
Arrow prefix, no icon → net8.0 → net8.0 A glyph instead of an SVG: nothing to draw, and it reads as “this version goes to net8.0”. Weakest as a shape, since an arrow is also what the row's own buttons use.
