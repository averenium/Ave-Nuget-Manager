# Плани робіт

Один файл на задачу: `NNN-slug.md`, де `NNN` — номер issue. План пишеться **до коду** і є єдиним, що передається між етапами: чат проектування його створює, чат дизайну доповнює посиланням на макет, чат імплементації виконує, чат перевірки звіряє результат із його критеріями готовності.

Це робочі документи, а не implementation notes. Коли задачу закрито, а тема виявилась достатньо великою, щоб її описувати постійно (як `http-backend-plan.md`), план переноситься в `docs/` і потрапляє в індекс `docs/README.md`. Решта планів лишається тут як історія рішень.

Мова — українська, як і решта `docs/`.
